# 评分系统回测验证框架

验证评分系统的有效性：**高分股票是否真的有更高收益？**

## 核心原理

1. **加载历史信号数据** - 从预生成的信号目录读取某日的信号
2. **计算未来收益** - 根据信号触发日期，计算之后1/3/5/10/20日的收益
3. **评分 vs 收益分析** - 分析不同评分区间的实际表现
4. **生成验证报告** - 相关性、胜率、收益率等关键指标

## 调整评分系统的依据

### 如果高分股票表现不佳

```
90分档 5日收益: 0.5% (预期>3%)
```

**可能原因**：
1. 信号协同分计算过高 - 降低 `(n-1) * 5` 的权重
2. 没有考虑市场状态 - 加入市场趋势过滤
3. 左右侧混合未充分惩罚 - 加强一致性检查

### 如果评分与收益无相关性

```
评分 vs 5日收益 相关性: 0.05
```

**调整方向**：
1. 重新设计评分维度
2. 引入历史胜率加权
3. 加入波动率惩罚

### 如果所有股票评分都高

```
评分范围: 75-100 (没有低分股票)
```

**问题**：门槛设置过低
**解决**：提高 strong 信号的判定标准，或引入更多扣分项

## 注意事项

1. **数据完整性**: 回测需要信号日期之后的历史价格数据
2. **样本量**: 单日样本可能不够，建议多日聚合验证
3. **市场环境**: 牛市/熊市中信号表现可能不同，需分段验证
4. **过拟合风险**: 不要用回测结果直接拟合评分参数
